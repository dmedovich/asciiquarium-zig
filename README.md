# Asciiquarium Zig 0.1.0

A Zig port of [Asciiquarium 1.1](https://robobunny.com/projects/asciiquarium/html/) by Kirk Baucom, with configurable fish names. It includes the original 16 fish sprites, water, castle, seaweed, bubbles, shark and hook interactions, ship, whale, sea monster, giant fish, swans, ducks, and dolphins.

## Install

### macOS — Homebrew

After the Homebrew tap is published:

```sh
brew tap dmedovich/tap
brew install asciiquarium-zig
```

Run:

```sh
asciiquarium-zig
```

### Linux and macOS — GitHub Releases

Download the archive for your platform from the GitHub Releases page:

- `asciiquarium-zig-0.1.0-linux-x86_64.tar.gz`
- `asciiquarium-zig-0.1.0-linux-aarch64.tar.gz`
- `asciiquarium-zig-0.1.0-macos-x86_64.tar.gz`
- `asciiquarium-zig-0.1.0-macos-aarch64.tar.gz`

Extract it and run:

```sh
./asciiquarium-zig
```

The release binaries do not require Perl, ncurses, or Zig.

## Build from source

Requires Zig **0.15.2**, libc, and a Unix-like terminal.

```sh
git clone https://github.com/dmedovich/asciiquarium-zig.git
cd asciiquarium-zig
zig build -Doptimize=ReleaseSafe
./zig-out/bin/asciiquarium-zig
```

Supported release targets are Linux x86_64/arm64 and macOS Intel/Apple Silicon.

## Controls

- `q` or Ctrl+C — quit
- `p` — pause/resume
- `r` — reload fish names and regenerate the scene

The scene adapts to terminal resizing. Minimum terminal size: 20×12; rendering is capped at 320×120 cells.

## Fish names

The config lookup order is:

1. `ASCIQUARIUM_CONFIG` if set.
2. `$XDG_CONFIG_HOME/asciiquarium/fish.conf`.
3. `~/.config/asciiquarium/fish.conf`.
4. `fish.conf` in the current directory.

A sample `fish.conf` is included with releases. The file contains one UTF-8 name per line. Blank lines and comments beginning with `#` are ignored. Up to 64 names of at most 95 bytes each are loaded. If no config file is found, fish swim without labels.

Example:

```sh
mkdir -p ~/.config/asciiquarium
cp fish.conf ~/.config/asciiquarium/fish.conf
```

Or use an explicit file:

```sh
ASCIQUARIUM_CONFIG=/path/to/my-fish.conf asciiquarium-zig
```

Cyrillic labels work in a UTF-8 terminal locale. Each Unicode code point is counted as one terminal cell, so wide East Asian characters and combining marks may not align exactly.

## Releases

Pushing a tag matching `v*.*.*` runs the release workflow. The tag version must match `VERSION`.

Example:

```sh
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions builds Linux x86_64/arm64 and macOS Intel/Apple Silicon archives, generates a source archive and `SHA256SUMS`, and attaches them to the GitHub Release.

## Homebrew tap

The repository contains a formula template at `packaging/homebrew/asciiquarium-zig.rb`. After publishing `v0.1.0`, replace its placeholder SHA-256 with the source archive checksum and copy the formula to:

```text
homebrew-tap/Formula/asciiquarium-zig.rb
```

Users can then install it with:

```sh
brew tap dmedovich/tap
brew install asciiquarium-zig
```
